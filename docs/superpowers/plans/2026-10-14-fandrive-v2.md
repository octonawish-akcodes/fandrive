# FanDrive v2 — proof, depth and reach

**Goal:** close the gaps the competitive review found: measured proof, deeper Qloo use, polish, and an agent-facing API.
**Spec:** docs/superpowers/specs/2026-10-13-fandrive-design.md (MCP endpoint, explainability, method page and consistency check are in its scope; the rest was approved in chat on 2026-10-14: "do everything").
**Rules:** TDD for every behaviour change; deploy after each task; never print keys; Qloo ≤ 3 req/s; record rulings in the ledger.

## Tasks
1. **Receipts + status.** Every Qloo request a plan makes is recorded (path, params without the key, cached or live) via AsyncLocalStorage; the plan carries `receipts`; the report shows a "Qloo receipts" drawer with Copy-as-curl (`$QLOO_API_KEY` placeholder). `/api/status` reports Qloo live, model chain and Redis; the header shows badges.
2. **Deeper Qloo.** (a) `urn:tag` insights: "fans also love" tags for the picked fandoms, shown on pick cards and given to the copy writer. (b) `/v2/tags` + `filter.tags` (union) host-venue query per fan zone (university, college, community centre, library, event venue, convention centre, stadium, arena, high school, gym, banquet hall), merged with the general venue query. (c) `/v2/trending` momentum for TV/film/artist/podcast picks, labelled with Qloo's window (data ends Sept 2025).
3. **Method page** `/method`: Qloo youth skew of past blood-drive partners (Metallica, Game of Thrones, NFL, Peanuts…) next to their published outcomes, framed as "consistent with", plus how scoring works and data limits. Data generated by a script into `src/data/method.json` (no live calls at view time).
4. **MCP endpoint** `/api/mcp` (mcp-handler): tools `plan_blood_drive`, `score_fandoms`, `city_strength`; same guards (rate limit, budget, input limits).
5. **20-city evaluation** `scripts/eval.ts`: FanDrive's top-3 vs plain AI's picks, fact-checked with Qloo: average youth skew, share of older-skewing picks, share Qloo can't find. Results to `docs/eval/` + README headline + `/method`.
6. **Outreach drafts** for US blood centres and Indian NSS/Rotaract units (`docs/outreach.md`).
7. **Ops:** Upstash (user accepts terms), redeploy, production smoke test after each task.
